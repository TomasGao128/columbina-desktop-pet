# 哥伦比娅桌宠使用说明

## 下载与启动

在仓库的 Releases 页面下载 `columbina-desktop-pet-v0.21.0-windows-x64.zip`，完整解压到可写目录（例如 `D:\桌宠`），然后双击 `启动哥伦比娅.vbs`。若系统无法运行 VBS，使用 `启动桌宠.cmd`。Windows x64 运行环境已包含在完整包中，无需安装 Node.js、Python 或 npm。

不要直接在压缩包里启动，也不要只解压 app 目录。运行 `创建启动快捷方式.vbs` 可创建适合当前路径的启动快捷方式。解压到新路径后需重新创建快捷方式。

GitHub 自动生成的 Source code 压缩包是源码，不含人物素材和运行环境；普通使用请选择上面的完整运行包。

## 基本操作

| 操作 | 效果 |
| --- | --- |
| 拖动人物身体 | 移动桌宠，松手后有落地反馈 |
| 拖到屏幕左右边缘 | 进入贴边探头状态；拖离可展开 |
| 点击头、胸、脚 | 不同文字气泡与动作，不播放部位触碰语音 |
| 连续点击 | 可触发晕眩互动 |
| 右键人物 | 打开动作、心情、姿势、换装秀、玩法等菜单 |
| 右键 → 控制中心 | 搜索动作、收藏、调节外观与互动、调整菜单顺序 |
| 右键 → 退出 | 正常退出并保存本机状态 |

默认按图片透明度判断身体命中，透明区域可操作后面的桌面；可在设置中调整点击穿透。人物动作和部分场景会暂时占用身体，切换动作或停止当前动作可收起表演。

## 动作、成长与收藏

动作和心情会显示气泡，部分带本地配音。姿势与换装秀直接显示在桌面上；选择后会暂时替换人物，结束后回到待机。星标可收藏支持收藏的项目。

互动会增加亲密度。升级时出现庆祝特效与气泡，并逐步解锁内容；换装秀按成长阶段开放 6、12、20、28 套。锁定项目需达到相应成长条件。

## 玩法与场景

- 一起做题：选择答案，查看反馈后继续。
- 节奏游戏：按提示使用 A/S/D/F，或点击界面按钮；空格可代替当前高亮键。
- 篮球：按住投篮按钮或空格蓄力，松开发球；可使用界面提供的模式与回放。
- 小黑互动：通过场景按钮摸头、抱抱、贴脸、膝上陪伴或逗猫。
- 风景陪伴：切换场景与光照，欣赏完整坐姿动画。

打开玩法后以界面当时显示的按钮和提示为准。Esc 可取消支持退出的当前表演。

## 氛围、声音与外观

控制中心可选择雨、风、晴夜、落雪、萤火、枫叶、落樱与蝴蝶等氛围，并调整可用参数。氛围不阻挡桌面点击。专注状态可暂停氛围显示。

偏好设置支持大小、透明度、声音、鼠标注视及互动手感等调整；「减少动画」可降低动态效果。菜单排序支持调整主菜单和子菜单，修改自动保存，可恢复默认。

## 存档与更新

退出桌宠后备份 `app/settings.json`，可保留成长与偏好。

更新时先退出旧版本，解压新版本到新目录，再按需迁移自己的设置；不要覆盖正在运行的文件。不要公开上传本机配置。

## 常见问题

- 无法启动：确认完整解压且存在 `runtime/electron.exe`，尝试 CMD 启动器；可检查 `app/error.log`。
- 提示缺素材：重新解压完整运行包；源码开发请补齐同版本 assets 包。
- 没有声音：检查控制中心音量和语音开关；头、胸、脚触碰及新增文字气泡本来就不会播放语音。
- 想恢复默认：优先在控制中心恢复对应设置；完整重置前先备份自己的存档。

## 当前范围

当前版本基于完整 PNG/WebP 动作帧，尚未实现 Live2D、语音通话、虚拟主播或 Steam MOD 接入。
