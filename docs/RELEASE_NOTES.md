# 哥伦比娅桌宠 v0.21.0

Windows x64 便携版。解压后双击「启动哥伦比娅.vbs」，无需安装开发环境。

## 本版内容

- 心情与动作共 28 项，各新增 3 条气泡，共 84 条情境文字。
- 28 种桌面姿势、28 套逐步解锁的换装秀，支持收藏。
- 拖动落地、贴边探头、鼠标注视、成长升级庆祝与八种氛围。
- 做题、节奏、篮球、小黑互动和风景陪伴。
- 控制中心支持外观、声音、互动手感与菜单排序。

## 下载选择

| 文件 | 用途 |
| --- | --- |
| `columbina-desktop-pet-v0.21.0-windows-x64.zip` | 普通用户：包含程序、全部素材、运行环境与说明 |
| `columbina-desktop-pet-v0.21.0-assets.zip` | 开发者：仅素材，按原路径解压到源码根目录 |
| `preview-*.png` | 姿势、坐姿、换装、贴边探头、升级特效与控制中心的真实运行预览 |
| `SHA256SUMS.txt` | 两个 ZIP 包的 SHA-256 校验值 |

完整包不含个人存档、日志或本机快捷方式。运行「创建启动快捷方式.vbs」可生成快捷方式。

当前采用 PNG/WebP 序列帧，尚不包含 Live2D 或 Steam MOD。多屏及不同 DPI 仍需按实际设备验证。
