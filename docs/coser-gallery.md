# 换装秀 · 桌面写真

右键桌宠 →「换装秀」展开缩略图菜单，点击任意服装后，完整透明人物直接显示在桌面上，不打开面板。随现有成长阶段解锁：初见6套；熟悉（20点且互动10次）12套；亲密（60点且互动30次）20套；挚友（140点）全部28套。升级提示与成长页面显示服装进度。

缩略图右上角星标用于收藏或取消收藏，收藏项优先排列，与控制中心常用收藏共用保存；未解锁服装不能通过收藏绕过解锁。

每次展示约 7.2 秒后恢复待机。可随时选择其他服装、原有姿势或动作，也可拖动取消。在「控制中心 → 菜单排序」中可调整分类及服装顺序，控制中心也支持收藏这些写真。

透明素材随工程保存在 `app/renderer/coser/`，清单见 `coser-poses.json`。使用用户提供的 28 张原始素材，通过内置 imagegen 去除白底，保留完整人物、服装和道具。处理提示词：移除白底及背景角落文字，保留白色衣服、皮肤与羽饰，不新增肢体、不裁切，输出透明 RGBA PNG。

服装写真接入现有动作目录与动画导演，不播放配音。复用当前图片透明度命中，不扩大点击范围；图片缓存继续受原 96 MiB 解码预算限制。旧图册窗口、预加载及导出代码已经移除。

姿势与换装特效的显示强度调至原来的42%，粒子从28/20个减少为16个。其他互动和亲密度升级特效不受影响。
