# 功能控制中心 · 0.18.1

右键桌宠 → 控制中心。面板可以重复打开，已有窗口会被唤起。

- 常用收藏：动作和氛围均可点击星标收藏，最多 40 项，再次点击移除。
- 动作与玩法：搜索动作名称或按分类筛选。沿用原有成长解锁规则，未解锁动作不能播放。左下角可停止当前动作。
- 天气氛围：晴夜、萤火、落雪等八种氛围，支持范围、密度和亮度调节，也可打开原详细面板。两个面板使用同一份配置。
- 偏好设置：角色大小、不透明度、泡泡显示、减少动画、点击穿透、音效、语音音量，以及互动手感。

视线速度为 50%–200%；拖动倾斜与探头幅度为 0%–150%，100% 保持原有效果，0% 关闭对应位移或倾斜。探头幅度调节的是探头反馈，不会裁切人物图片。

滑块即时应用并保存。外观、声音、互动手感各自恢复默认，不影响其他组、成长与收藏。外观默认大小 140%、不透明度 100%、泡泡和点击穿透开启、减少动画关闭；声音默认开启、语音音量 75%；互动手感默认视线开启、三项参数 100%。头、胸、脚触碰仍不播放语音。

通过原右键菜单修改设置后，点击“刷新当前状态”同步面板显示。陪伴聊天和论文记录继续分开保存，主动分享保持关闭。

控制面板不读取聊天记录和 API 密钥。主进程校验面板来源，角色进程校验动作、收藏及参数；偏好通过现有设置白名单保存。天气仍由原天气服务管理，动作仍由原动画导演调度。

## 菜单排序

进入「菜单排序」，选择主菜单或某个分类的子菜单，拖动条目到目标位置；也可点击 ↑ / ↓。顺序立即应用并保存在本机，重启后保留。点击「恢复全部菜单默认顺序」清除自定义排列。新版本新增的菜单项会出现在已排序条目之后，原有解锁规则不变。
