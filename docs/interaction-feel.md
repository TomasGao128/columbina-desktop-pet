# 互动手感

0.13.0 使用现有完整角色素材，没有新增姿势图或拆分身体。

- 轻点头部仍播放原来的文字与动作，不播放录音。按住约 550 毫秒且未移动超过拖动阈值，进入抚摸；可以轻轻移动鼠标，松手时显示不同的结束反馈。
- 按住之前快速移动仍是拖动；抚摸过程中角色拥有独立动作状态，松手、取消、失焦、切换动作或重载都会清理状态。抚摸奖励最多每 20 秒一次，松手后的兼容点击不会重复触发。
- 拖动按速度产生最多 5 度的轻微倾斜，停止移动逐渐回正，松手平稳恢复。整张角色图一起变换，身体命中范围随之更新。
- 距屏幕边缘较近时先显示已有探头姿势，松手达到吸附范围后约 160 毫秒缓动滑入。左右使用原有不同隐藏深度。已吸附时，鼠标靠近头部再向屏幕内探出少许，离开后收回；不裁切身体或扩大透明处点击范围。
- 同一种动作的文字避免紧邻重复；反馈池仍是本项目原创台词，不称为官方剧情对白。

专注、睡眠、其他动作或弹窗期间不开始抚摸；减弱动画时关闭倾斜、滑入和闪动，保留静态光点及文字。主动分享继续关闭，陪伴和论文的记录、记忆保持分离。
