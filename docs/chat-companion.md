# 陪伴记忆、分离记录与表情联动

当前版本 0.12.0。主动分享关闭；没有定时小心事或自动 API 请求，旧主动分享偏好也不再生效。既有互动触发的动作、反馈和故事可继续使用。

## 使用

陪伴聊天侧栏的「陪伴记忆」可添加称呼、喜好、近况，也可修改、忘记单条或忘记全部。聊天中的「记住这句」先打开确认表单，不会直接保存；发送「记住：喜欢安静的雨天」或「记住，以后叫我阿高」则明确保存。普通闲聊不自动提取个人档案。

最多 32 条，每条 240 字。修改称呼替换原称呼，重复内容不重复保存。记忆由用户选择保留，与保存消息的开关独立：关闭消息保存不删除这些明确指定的记忆。忘记会删除长期记忆，但不会改写既有消息；想让旧消息也退出上下文，可另行清空陪伴记录。

近况只在用户发来相关消息时帮助接话，不自动提醒，不每次询问进展。资料不足不会编造记忆。模型可能仍有发挥差异，并非把每条记忆变成必说台词。

## 记录边界

- `app/chat-history.json`：只有陪伴聊天。
- `app/paper-history.json`：只有论文修改。
- `app/polish-history.json`：只有文字润色。
- `app/summary-history.json`：只有摘要。
- `app/chat-memories.json`：只有用户明确指定的陪伴记忆。

旧版混合记录首次读取时按原模式迁移，先写目标文件，再改写陪伴文件。保留旧内容，不导入论文记忆。陪伴历史里旧的论文相关回合保留供查看，但不再作为陪伴请求上下文。清空只作用于当前模式，其他记录与长期记忆保留。每个模式有自己的条数和字符上限，论文不会挤掉日常对话。

输入草稿按模式独立，切换模式会还原各自草稿。陪伴中输入论文内容会提示切换「论文修改」，不会把它发往陪伴模型，也不写入陪伴记录。关键词边界可能拦截含有论文或导师等词的日常消息，可去文字助手处理；不自动搬运输入内容。

API 密钥仍由本机加密保存，所有记录与记忆文件都已排除 Git。记忆以本机文本文件保存；仅陪伴请求会把它发送至用户配置的 API，论文、润色与摘要请求不包含陪伴记忆。

## 表情联动

完成陪伴回复后，按用户这轮话语匹配开心、好奇、被夸、安慰四种反馈，调用现有整体角色帧并展示回复气泡；未匹配则只显示气泡。简单规则不等同于全面的情感理解。

不增加亲密度，不播放录音，不打断游戏、睡眠、专注、拖动、吸附或其他动作；没有补播队列。减弱动画时只展示完整的一帧。动作结束、取消或资源加载失败都释放角色状态。

另用临时目录中的合成记忆完成四轮真实 API 试聊，重新创建记忆存储后仍能回应称呼、雨天喜好及公园散步的近况；没有发送用户真实历史或把试聊写入用户文件。事实测试和短测不保证所有长对话的角色扮演质量。
